<p><strong>GitHub</strong>&nbsp;(&nbsp;<a href="https://en.wikipedia.org/wiki/Help:IPA/English">/&nbsp;ˈ&nbsp;ɡ&nbsp;ə&nbsp;t&nbsp;.h&nbsp;ʌ&nbsp;b&nbsp;/​</a>&nbsp;<a href="https://upload.wikimedia.org/wikipedia/commons/transcoded/7/74/En-us-GitHub.ogg/En-us-GitHub.ogg.mp3"></a><sup><a href="https://en.wikipedia.org/wiki/File:En-us-GitHub.ogg">ⓘ</a></sup>&nbsp;) เป็น<a href="https://en.wikipedia.org/wiki/Proprietary_software">ที่เป็นกรรมสิทธิ์</a>ซึ่งช่วยให้นักพัฒนาสามารถสร้าง จัดเก็บ จัดการ และแบ่งปันโค้ดของตนได้ โดยใช้<a href="https://en.wikipedia.org/wiki/Git">Git</a>เพื่อให้<a href="https://en.wikipedia.org/wiki/Distributed_version_control">การควบคุมเวอร์ชันแบบกระจาย</a>และ GitHub เองก็ให้<a href="https://en.wikipedia.org/wiki/Access_control">การควบคุมการเข้าถึง</a>การติดตาม<a href="https://en.wikipedia.org/wiki/Bug_tracking_system">ข้อบกพร่อง</a>คำขอ<a href="https://en.wikipedia.org/wiki/Software_feature">คุณสมบัติซอฟต์แวร์</a>การ<a href="https://en.wikipedia.org/wiki/Task_management">จัดการงาน การบูร</a><a href="https://en.wikipedia.org/wiki/Continuous_integration">ณาการอย่างต่อเนื่อง</a>และ<a href="https://en.wikipedia.org/wiki/Wiki">วิกิ</a>สำหรับทุกโครงการ<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-hugeinvestment-9">&nbsp;[&nbsp;9&nbsp;]</a></sup>&nbsp;GitHub ซึ่งมีสำนักงานใหญ่ใน<a href="https://en.wikipedia.org/wiki/San_Francisco">ซานฟรานซิสโก</a>ดำเนินการโดย Github, Inc. ซึ่งเป็นบริษัทในเครือของ<a href="https://en.wikipedia.org/wiki/Microsoft">Microsoft</a>ตั้งแต่ปี 2018<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-techcrunch-10">&nbsp;[&nbsp;10&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>โดยทั่วไปมักใช้เพื่อโฮสต์โครงการพัฒนาซอฟต์แวร์<a href="https://en.wikipedia.org/wiki/Open_source">โอเพนซอร์ส</a><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-11">[&nbsp;11&nbsp;]</a></sup>&nbsp;ณ เดือนมกราคม พ.ศ. 2566,GitHub รายงานว่ามีนักพัฒนามากกว่า 100 ล้านคนและ&nbsp;<a href="https://en.wikipedia.org/wiki/Repository_(version_control)">คลังเก็บข้อมูล</a>&nbsp;มากกว่า 420&nbsp;&nbsp;ล้านแห่งรวม ถึง&nbsp;คลังเก็บข้อมูลสาธารณะอย่างน้อย 28 ล้านแห่ง&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-12">[</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-12">&nbsp;12&nbsp;</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-12">]</a></sup>&nbsp;ถือเป็น ผู้ให้บริการ<a href="https://en.wikipedia.org/wiki/Source_code">โฮสต์ซอร์สโค้ด</a>ที่ใหญ่ที่สุดในโลกณ เดือนมิถุนายน2023<a href="https://en.wikipedia.org/wiki/Repository_(version_control)"></a>&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-12"></a></sup><a href="https://en.wikipedia.org/wiki/Source_code"></a>&nbsp;.ในปี 2024 มีนักพัฒนาซอฟต์แวร์มากกว่า 5,000 ล้านคนร่วมให้ข้อมูลในโครงการโอเพนซอร์สมากกว่า 500 ล้านโครงการ<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-13">[&nbsp;13&nbsp;]</a></sup></p>

<h2 class="wp-block-heading">เกี่ยวกับ</h2>
<!-- /wp:heading -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading">การก่อตั้ง</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>การพัฒนาแพลตฟอร์ม GitHub เริ่มขึ้นเมื่อวันที่ 19 ตุลาคม พ.ศ. 2550&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-githubfirstcommit-14">[&nbsp;14&nbsp;]</a></sup>เว็บไซต์นี้เปิดตัวในเดือนเมษายน พ.ศ. 2551 โดย<a href="https://en.wikipedia.org/wiki/Tom_Preston-Werner">Tom Preston-Werner</a>&nbsp;,&nbsp;<a href="https://en.wikipedia.org/wiki/Chris_Wanstrath">Chris Wanstrath</a>&nbsp;,&nbsp;<a href="https://en.wikipedia.org/wiki/P._J._Hyett">PJ Hyett</a>และ Scott Chacon หลังจากที่เปิดให้ใช้งานใน<a href="https://en.wikipedia.org/wiki/Beta_release">เวอร์ชันเบต้า</a>&nbsp;มาได้ สอง สามเดือน&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-pastie-15">[&nbsp;15&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading">โครงสร้างขององค์กร</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>เดิมที GitHub เป็น<a href="https://en.wikipedia.org/wiki/Flat_organization">องค์กรแบบราบเรียบ</a>ที่ไม่มีผู้จัดการระดับกลาง แต่พึ่งพา<a href="https://en.wikipedia.org/wiki/Workers'_self-management">การจัดการตนเอง</a>แทน<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-cto-mgmt-style-16">[&nbsp;16&nbsp;]</a></sup>พนักงานสามารถเลือกทำงานในโครงการที่ตนสนใจได้ (&nbsp;<a href="https://en.wikipedia.org/wiki/Open_allocation">การจัดสรรแบบเปิด</a>&nbsp;) แต่ประธานเจ้าหน้าที่บริหารเป็นผู้กำหนดเงินเดือน<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-nyt-17">[&nbsp;17&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>ในปี 2014 บริษัทได้เพิ่มระดับ<a href="https://en.wikipedia.org/wiki/Middle_management">การจัดการระดับกลาง</a>เพื่อตอบสนองต่อข้อกล่าวหาเรื่องการล่วงละเมิดทางเพศต่อผู้ร่วมก่อตั้งและซีอีโอในขณะนั้น โทมัส เพรสตัน-เวอร์เนอร์ และภรรยาของเขา เทเรซา จากผลของเรื่องอื้อฉาวดังกล่าว เพรสตัน-เวอร์เนอร์จึงลาออกจากตำแหน่งซีอีโอ<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-wsj-2014-18">[&nbsp;18&nbsp;]</a></sup>คริส แวนสแตรธ ผู้ร่วมก่อตั้งและหัวหน้าฝ่ายผลิตภัณฑ์<a href="https://en.wikipedia.org/wiki/Chris_Wanstrath">ได้</a>ขึ้นเป็นซีอีโอ<a href="https://en.wikipedia.org/wiki/Julio_Avalos">จูลิโอ อาวาโลส</a>ซึ่งในขณะนั้นดำรงตำแหน่งที่ปรึกษาทั่วไปและเจ้าหน้าที่ฝ่ายบริหาร ได้เข้าควบคุมการดำเนินงานทางธุรกิจและการจัดการประจำวันของ GitHub&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-19">[&nbsp;19&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:heading {"level":3} -->
<h3 class="wp-block-heading">การเงิน</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>GitHub เป็น<a href="https://en.wikipedia.org/wiki/Startup_company">ธุรกิจสตาร์ทอัพที่เริ่มต้น ด้วยเงินทุน&nbsp;</a><a href="https://en.wikipedia.org/wiki/Entrepreneurship#Bootstrapping">ส่วนตัว</a>&nbsp;ซึ่งในช่วงปีแรก ๆ มีรายได้เพียงพอที่จะได้รับเงินทุนจากผู้ก่อตั้งทั้งสามคนและเริ่มจ้างพนักงาน<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-20">[</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-20">&nbsp;20&nbsp;</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-20">]</a></sup><a href="https://en.wikipedia.org/wiki/Startup_company"></a><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-20"></a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->

<h3 class="wp-block-heading">ประวัติศาสตร์</h3>

<!-- wp:paragraph -->
<p>บริการ GitHub ได้รับการพัฒนาโดย<a href="https://en.wikipedia.org/wiki/Chris_Wanstrath">Chris Wanstrath</a>&nbsp;,&nbsp;<a href="https://en.wikipedia.org/wiki/P._J._Hyett">PJ Hyett</a>&nbsp;,&nbsp;<a href="https://en.wikipedia.org/wiki/Tom_Preston-Werner">Tom Preston-Werner</a>และ Scott Chacon โดยใช้<a href="https://en.wikipedia.org/wiki/Ruby_on_Rails">Ruby on Rails</a>และเริ่มต้นในเดือนกุมภาพันธ์ พ.ศ. 2551&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-25">[&nbsp;25&nbsp;]</a></sup>บริษัท GitHub, Inc. ก่อตั้งขึ้นในปี พ.ศ. 2550 และตั้งอยู่ในซานฟรานซิสโก<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-26">[&nbsp;26&nbsp;]</a></sup></p>

<!-- wp:paragraph -->
<p>เมื่อวันที่ 24 กุมภาพันธ์ พ.ศ. 2552 GitHub ประกาศว่าภายในปีแรกของการเปิดให้บริการ GitHub ได้สะสมคลังเก็บข้อมูลสาธารณะมากกว่า 46,000 แห่ง โดย 17,000 แห่งนั้นถูกสร้างขึ้นในเดือนก่อนหน้า<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-:2-27">[&nbsp;27&nbsp;]</a></sup>ในขณะนั้น มีคลังเก็บข้อมูลประมาณ 6,200 แห่งที่ถูก<a href="https://en.wikipedia.org/wiki/Fork_(software_development)">แยกออกไป</a>อย่างน้อยหนึ่งครั้ง และ 4,600 แห่งถูกรวมเข้าด้วยกัน<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-:2-27">[&nbsp;27&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>ในปีเดียวกันนั้น เว็บไซต์ดังกล่าวมีผู้ใช้งานมากกว่า 100,000 ราย ตามข้อมูลจาก GitHub&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-28">[&nbsp;28&nbsp;]</a></sup>และเติบโตขึ้นจนมีคลังเก็บข้อมูลสาธารณะที่ไม่ซ้ำกันถึง 90,000 แห่ง โดยมีคลังเก็บข้อมูล 12,000 แห่งที่ถูกแยกออกไปอย่างน้อยหนึ่งครั้ง รวมเป็นคลังเก็บข้อมูลทั้งหมด 135,000 แห่ง<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-29">[&nbsp;29&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>ในปี 2010 GitHub มีคลังเก็บข้อมูล 1 ล้านแห่ง<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-30">[&nbsp;30&nbsp;]</a></sup>หนึ่งปีต่อมา จำนวนนี้เพิ่มขึ้นเป็นสองเท่า<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-31">[&nbsp;31&nbsp;]</a></sup>&nbsp;<a href="https://en.wikipedia.org/wiki/ReadWriteWeb">ReadWriteWeb</a>รายงานว่า GitHub แซงหน้า<a href="https://en.wikipedia.org/wiki/SourceForge">SourceForge</a>และ<a href="https://en.wikipedia.org/wiki/Google_Code">Google Code</a>ในจำนวนการคอมมิตทั้งหมดในช่วงเดือนมกราคมถึงพฤษภาคม 2011&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-32">[&nbsp;32&nbsp;]</a></sup>เมื่อวันที่ 16 มกราคม 2013 GitHub มีผู้ใช้งานเกิน 3 ล้านคน และมีคลังเก็บข้อมูลมากกว่า 5 ล้านแห่ง<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-33">[&nbsp;33&nbsp;]</a></sup>เมื่อสิ้นปี จำนวนคลังเก็บข้อมูลเพิ่มขึ้นเป็นสองเท่า โดยมีจำนวนถึง 10 ล้านแห่ง<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-34">[&nbsp;34&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>ในปี 2015 GitHub ได้เปิดสำนักงานในประเทศญี่ปุ่น ซึ่งเป็นสำนักงานแห่งแรกนอกสหรัฐอเมริกา<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-35">[&nbsp;35&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>เมื่อวันที่ 28 กุมภาพันธ์ พ.ศ. 2561 GitHub ตกเป็นเหยื่อของ การโจมตี&nbsp;<a href="https://en.wikipedia.org/wiki/Distributed_denial-of-service">แบบปฏิเสธการให้บริการแบบกระจาย</a>&nbsp;(DDoS) ครั้งใหญ่เป็นอันดับสามในประวัติศาสตร์ โดยมีปริมาณการรับส่งข้อมูลขาเข้าสูงสุดประมาณ 1.35 เทราบิตต่อวินาที<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-DDOS-36">[&nbsp;36&nbsp;]</a></sup></p>

<h2 class="wp-block-heading">บริการ</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>สามารถเข้าถึงและจัดการโปรเจ็กต์บน GitHub ได้โดยใช้ส่วนต่อประสานบรรทัดคำสั่ง<a href="https://en.wikipedia.org/wiki/Git">Git มาตรฐาน คำสั่ง Git มาตรฐานทั้งหมดใช้งานได้กับ GitHub นอกจากนี้ GitHub ยังอนุญาตให้ผู้ใช้เรียกดู&nbsp;</a><a href="https://en.wikipedia.org/wiki/Content_repository">ที่เก็บข้อมูล</a>&nbsp;สาธารณะ บนเว็บไซต์ได้อีกด้วย มีไคลเอนต์เดสก์ท็อปและ<a href="https://en.wikipedia.org/wiki/Plug-in_(computing)">ปลั๊กอิน</a>&nbsp;Git หลายตัว ให้เลือกใช้ ยิ่งไปกว่านั้น เว็บไซต์ยังให้ บริการฟังก์ชันคล้าย&nbsp;<a href="https://en.wikipedia.org/wiki/Social_networking">เครือข่ายสังคม</a>เช่น ฟีด ผู้ติดตาม วิกิ (โดยใช้<a href="https://en.wikipedia.org/wiki/Wiki_software">ซอฟต์แวร์วิกิ</a>ที่เรียกว่า<a href="https://en.wikipedia.org/wiki/Gollum_Wiki">Gollum</a>&nbsp;) และ<a href="https://en.wikipedia.org/wiki/Collaboration_graph">กราฟเครือข่ายสังคม</a>เพื่อแสดงว่านักพัฒนาทำงานกับเวอร์ชัน ("&nbsp;<a href="https://en.wikipedia.org/wiki/Fork_(software_development)">forks</a>&nbsp;") ของที่เก็บข้อมูลอย่างไร และ fork ใด (และสาขาภายใน fork นั้น) เป็นเวอร์ชันใหม่ล่าสุด</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>ทุกคนสามารถเรียกดูและดาวน์โหลดคลังเก็บข้อมูลสาธารณะได้ แต่เฉพาะผู้ใช้ที่ลงทะเบียนเท่านั้นที่สามารถมีส่วนร่วมในเนื้อหาในคลังเก็บข้อมูลได้ ด้วยบัญชีผู้ใช้ที่ลงทะเบียน ผู้ใช้สามารถสนทนา จัดการคลังเก็บข้อมูล ส่งผลงานไปยังคลังเก็บข้อมูลของผู้อื่น และ<a href="https://en.wikipedia.org/wiki/Code_review">ตรวจสอบการเปลี่ยนแปลงโค้ดได้</a>&nbsp;GitHub เริ่มให้บริการคลังเก็บข้อมูลส่วนตัวแบบจำกัดโดยไม่เสียค่าใช้จ่ายในเดือนมกราคม 2019 (จำกัดผู้ร่วมงานสามคนต่อโครงการ) ก่อนหน้านี้ มีเพียงคลังเก็บข้อมูลสาธารณะเท่านั้นที่ให้บริการฟรี<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-71">[&nbsp;71&nbsp;]&nbsp;</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-72">[&nbsp;72&nbsp;]&nbsp;</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-:3-73">[&nbsp;73&nbsp;]</a></sup>เมื่อวันที่ 14 เมษายน 2020 GitHub ได้เปิดให้ใช้งาน "ฟีเจอร์หลักทั้งหมดของ GitHub" ฟรีสำหรับทุกคน รวมถึง "คลังเก็บข้อมูลส่วนตัวที่มีผู้ร่วมงานไม่จำกัดจำนวน"&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-74">[&nbsp;74&nbsp;]</a></sup>ในเดือนพฤษภาคม 2019 Github, Inc. เริ่มเข้ารหัสซอร์สโค้ดบน github.com โดยค่าเริ่มต้น<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-75">[&nbsp;75&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>ซอฟต์แวร์พื้นฐานที่รองรับ GitHub คือ<a href="https://en.wikipedia.org/wiki/Git">Git</a>ซึ่งเขียนโดย<a href="https://en.wikipedia.org/wiki/Linus_Torvalds">Linus Torvalds</a>ผู้สร้าง Linux ซอฟต์แวร์เพิ่มเติมที่ให้ส่วนติดต่อผู้ใช้ของ GitHub นั้นเขียนขึ้นโดยใช้<a href="https://en.wikipedia.org/wiki/Ruby_on_Rails">Ruby on Rails</a>และ<a href="https://en.wikipedia.org/wiki/Erlang_(programming_language)">Erlang</a>โดยนักพัฒนาของ GitHub, Inc. ได้แก่ Wanstrath,&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-wanstrathinterview-76">[&nbsp;76&nbsp;]</a></sup>&nbsp;Hyett และ Preston-Werner</p>

<h3 class="wp-block-heading">ขอบเขต</h3>

<!-- wp:paragraph -->
<p>จุดประสงค์หลักของ GitHub คือการอำนวยความสะดวกใน<a href="https://en.wikipedia.org/wiki/Version_control">การควบคุมเวอร์ชัน</a>และ<a href="https://en.wikipedia.org/wiki/Issue_tracking_system">การติดตามปัญหา</a>ในการพัฒนาซอฟต์แวร์ มีป้ายกำกับ เหตุการณ์สำคัญ การมอบหมายความรับผิดชอบ และเครื่องมือค้นหาสำหรับการติดตามปัญหา สำหรับการควบคุมเวอร์ชัน Git (และ GitHub) อนุญาตให้ส่ง<a href="https://en.wikipedia.org/wiki/Pull_request">คำขอแก้ไข (pull request)</a>เพื่อเสนอการเปลี่ยนแปลงในซอร์สโค้ด ผู้ใช้ที่สามารถตรวจสอบการเปลี่ยนแปลงที่เสนอจะเห็นความแตกต่างระหว่างการเปลี่ยนแปลงที่ร้องขอและอนุมัติการเปลี่ยนแปลงนั้น ในศัพท์ของ Git การกระทำนี้เรียกว่า "การคอมมิต" (committing) และหนึ่งตัวอย่างของการคอมมิตคือ "คอมมิต" (commit) ประวัติของคอมมิตทั้งหมดจะถูกเก็บไว้และสามารถดูได้ในภายหลัง</p>

<h3 class="wp-block-heading">GitHub Actions</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>GitHub Actions เปิดตัวอย่างเป็นทางการเมื่อวันที่ 13 พฤศจิกายน 2019 มีการประกาศครั้งแรกในเดือนตุลาคม 2018 ที่ GitHub Universe ในฐานะวิธีการทำให้เวิร์กโฟลว์เป็นไปโดยอัตโนมัติ แต่การเปิดตัวแบบเต็มรูปแบบ (GA) เกิดขึ้นในอีกหนึ่งปีต่อมาในปี 2019 GitHub Actions&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-101">[&nbsp;101&nbsp;]</a></sup>ช่วยให้สามารถสร้าง ไปป์ไลน์&nbsp;<a href="https://en.wikipedia.org/wiki/Continuous_integration">การรวมระบบอย่างต่อเนื่อง</a>และ<a href="https://en.wikipedia.org/wiki/Continuous_deployment">การปรับใช้แบบต่อเนื่อง</a>สำหรับการทดสอบ การเผยแพร่ และการปรับใช้ซอฟต์แวร์โดยไม่ต้องใช้เว็บไซต์/แพลตฟอร์มของบุคคลที่สาม แตกต่างจากเครื่องมือ CI/CD อื่นๆ มากมาย GitHub Actions เปิดตัวพร้อมกับตลาดกลางที่นักพัฒนาสามารถแบ่งปันและนำแอ็กชันที่สร้างไว้ล่วงหน้า (เช่น การทดสอบ การตรวจสอบโค้ด การปรับใช้) กลับมาใช้ใหม่ได้ GitHub ต้องการลดการพึ่งพาบริการของบุคคลที่สามและรักษานักพัฒนาให้อยู่ภายในระบบนิเวศของ GitHub GitHub Actions ให้บริการรันเนอร์แบบโฮสต์ (Linux, Windows, macOS) ที่สามารถปรับขนาดได้แบบไดนามิก ช่วยลดความจำเป็นในการจัดการเซิร์ฟเวอร์สร้างด้วยตนเอง</p>

<h3 class="wp-block-heading">สาระสำคัญ</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>GitHub ยังดำเนินการเว็บไซต์สไตล์<a href="https://en.wikipedia.org/wiki/Pastebin">pastebin ที่เรียกว่า&nbsp;</a><strong>Gist</strong>ซึ่งใช้สำหรับ<a href="https://en.wikipedia.org/wiki/Snippet_(programming)">โค้ดสั้นๆ</a>ต่างจาก GitHub เองซึ่งมักใช้สำหรับโครงการขนาดใหญ่<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-pastie-15">[&nbsp;15&nbsp;]</a></sup>&nbsp;Tom Preston-Werner เปิดตัวฟีเจอร์นี้ในงานประชุม Ruby ในปี 2008&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-102">[&nbsp;102&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Gist สร้างขึ้นบนแนวคิดพื้นฐานที่เรียบง่ายของ<a href="https://en.wikipedia.org/wiki/Pastebin">pastebin</a>โดยเพิ่มการควบคุมเวอร์ชันสำหรับโค้ดสั้นๆ การ fork ที่ง่าย และ<a href="https://en.wikipedia.org/wiki/Transport_Layer_Security">การเข้ารหัส TLS</a>สำหรับการวางแบบส่วนตัว เนื่องจาก "gist" แต่ละรายการเป็นที่เก็บ Git ของตัวเอง โค้ดสั้นๆ หลายรายการจึงสามารถบรรจุอยู่ในหน้าเดียวได้ และสามารถ push และ pull ได้โดยใช้ Git&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-103">[&nbsp;103&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>ผู้ใช้ที่ไม่ได้ลงทะเบียนสามารถอัปโหลด Gists ได้จนถึงวันที่ 19 มีนาคม 2561 ซึ่งหลังจากนั้นการอัปโหลด Gists จะถูกจำกัดเฉพาะผู้ใช้ที่เข้าสู่ระบบแล้วเท่านั้น โดยมีรายงานว่าเพื่อลด<a href="https://en.wikipedia.org/wiki/Spamming">การสแปม</a>บนหน้า Gists ล่าสุด<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-104">[&nbsp;104&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a href="https://en.wikipedia.org/wiki/URL">URL</a>ของ Gists&nbsp;ใช้รหัสเลขฐานสิบหก และการแก้ไข Gists จะถูกบันทึกไว้ใน<a href="https://en.wikipedia.org/wiki/Version_control">ประวัติการแก้ไข</a>ซึ่งสามารถแสดงความแตกต่างของข้อความได้ถึงสามสิบการแก้ไขต่อหน้า โดยมีตัวเลือกให้เลือกระหว่างมุมมองแบบ "แยก" และ "รวม" เช่นเดียวกับที่เก็บข้อมูล Gists สามารถคัดลอก "ติดดาว" (เช่น คั่นหน้าแบบสาธารณะ) และแสดงความคิดเห็นได้ จำนวนการแก้ไข ดาว และการคัดลอกจะแสดงอยู่ในหน้า Gist&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-105">[&nbsp;105&nbsp;]</a></sup></p>

<h2 class="wp-block-heading">GitHub Copilot</h2>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>บทความหลัก:&nbsp;</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a href="https://en.wikipedia.org/wiki/GitHub_Copilot">GitHub Copilot</a></p>
<!-- /wp:paragraph -->

<!-- wp:image {"linkDestination":"custom","anchor":"mwAx8"} -->
<figure class="wp-block-image" id="mwAx8"><a class="mw-file-description" href="https://en.wikipedia.org/wiki/File:GitHub_Codespaces_side_by_side_terminal.webp"><img src="https://upload.wikimedia.org/wikipedia/commons/thumb/a/a9/GitHub_Codespaces_side_by_side_terminal.webp/250px-GitHub_Codespaces_side_by_side_terminal.webp.png" alt=""/></a><figcaption class="wp-element-caption"><a href="https://en.wikipedia.org/wiki/GitHub_Codespaces"></a>โครงสร้างของ<a href="https://en.wikipedia.org/wiki/GitHub_Codespaces">GitHub Codespaces :</a><br><a href="https://en.wikipedia.org/wiki/GitHub_Copilot">GitHub Copilot</a>อยู่ทางซ้าย โปรแกรม<br>แก้ไขโค้ดอยู่ตรงกลาง และเทอร์<br>มินัลอยู่ทางขวา</figcaption></figure>
<!-- /wp:image -->

<!-- wp:paragraph -->
<p>GitHub Copilot เป็นหนึ่งใน เครื่องมือช่วยพัฒนาซอฟต์แวร์ที่ใช้&nbsp;<a href="https://en.wikipedia.org/wiki/AI">AI</a>&nbsp;เป็นหลักที่ได้รับการยอมรับอย่างกว้างขวางเป็นครั้งแรก เวอร์ชันทดลองใช้งานเปิดตัวในปี 2021 สำหรับ ผู้ใช้&nbsp;<a href="https://en.wikipedia.org/wiki/VSCode">VSCode</a>และอิงตามโมเดล Codex ของ<a href="https://en.wikipedia.org/wiki/OpenAI">OpenAI&nbsp;</a><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-119">[&nbsp;119&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>GitHub Copilot พร้อมใช้งานแล้วบน GitHub.com โดยตรง บน<a href="https://en.wikipedia.org/wiki/Command_line">บรรทัดคำสั่ง</a>รวมถึงใน<a href="https://en.wikipedia.org/wiki/Integrated_development_environment">IDE</a>&nbsp;ต่างๆ ผู้ใช้สามารถเลือกใช้<a href="https://en.wikipedia.org/wiki/LLM">LLM (Learning Language Management)</a>&nbsp;ที่หลากหลาย สำหรับบางฟีเจอร์ได้</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>คำขอของผู้ใช้ในการบล็อกฟีเจอร์ Copilot เป็นหัวข้อที่ได้รับความนิยมมากที่สุดอันดับ 1 และ 2 ในช่วง 12 เดือนที่ผ่านมาบนหน้าชุมชนองค์กรของ GitHub ณ เดือนกันยายน 2025 หัวข้อเหล่านี้ยังคงไม่มีคำตอบ ผู้ใช้และโครงการบางส่วนได้ย้ายไป<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-120">ใช้</a></sup><a href="https://en.wikipedia.org/wiki/Open_source">&nbsp;ทางเลือก โอเพนซอร์ส</a>เช่น<a href="https://en.wikipedia.org/wiki/Codeberg">Codeberg</a>&nbsp;[&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-120">120&nbsp;</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-120">]</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-120"></a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>เวิร์กโฟลว์ตัวแทน</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>GitHub Agentic Workflows เป็นระบบจากทีม GitHub Next ที่ช่วยให้นักพัฒนาสามารถสร้างงานอัตโนมัติที่ขับเคลื่อนด้วย AI ในขณะที่ยังคงรักษามาตรการรักษาความปลอดภัยที่เข้มงวด แตกต่างจากการทำงานอัตโนมัติแบบดั้งเดิม คุณกำหนดเวิร์กโฟลว์โดยใช้ข้อความแจ้งด้วยภาษาธรรมชาติ และระบบจะดำเนินการสิ่งเหล่านี้ในฐานะเอเจนต์ด้วยชุดเครื่องมือที่จำกัดและปลอดภัย<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-121">[&nbsp;121&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>ที่สำคัญคือ เอージェนต์เหล่านี้ไม่สามารถกระทำการใดๆ ตามอำเภอใจได้ พวกมันส่งเจตนา (คำขอที่มีโครงสร้าง) ซึ่งจะถูกประมวลผลโดยตัวจัดการที่มีความปลอดภัยสูงและจำกัด เพื่อให้แน่ใจว่าจะมีเพียงการกระทำที่ได้รับอนุญาตเท่านั้นที่จะถูกดำเนินการ</p>

<h2 class="wp-block-heading">โปรแกรมเก็บข้อมูล GitHub</h2>

<p><a href="https://en.wikipedia.org/wiki/GitHub_Archive_Program">โปรแกรมเก็บข้อมูลของ GitHub</a></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>ในเดือนกรกฎาคม พ.ศ. 2563 GitHub ได้จัดเก็บไฟล์เก็บถาวรของเว็บไซต์ในเดือนกุมภาพันธ์<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-blog-64">[&nbsp;64&nbsp;]</a></sup>ไว้ในเหมืองร้างบนภูเขาใน<a href="https://en.wikipedia.org/wiki/Svalbard">สฟาลบาร์ด</a>ประเทศนอร์เวย์ ซึ่งเป็นส่วนหนึ่งของ<a href="https://en.wikipedia.org/wiki/Arctic_World_Archive">Arctic World Archive</a>และอยู่ไม่ไกลจาก<a href="https://en.wikipedia.org/wiki/Svalbard_Global_Seed_Vault">Svalbard Global Seed Vault</a>ไฟล์เก็บถาวรนี้ประกอบด้วยโค้ดของคลังเก็บข้อมูลสาธารณะที่ใช้งานอยู่ทั้งหมด รวมถึงโค้ดของคลังเก็บข้อมูลสาธารณะที่ไม่ได้ใช้งานแต่มีความสำคัญ ข้อมูลขนาด 21&nbsp;<a href="https://en.wikipedia.org/wiki/Terabyte">TB</a>ถูกจัดเก็บไว้ในม้วนฟิล์มเก็บถาวร<em>piqlFilm ใน&nbsp;</em><a href="https://en.wikipedia.org/wiki/Barcode#Matrix_(2D)_barcodes">รูปแบบบาร์โค้ดเมทริกซ์ (2D)</a>&nbsp;(&nbsp;<a href="https://en.wikipedia.org/wiki/Boxing_barcode">บาร์โค้ด Boxing</a>&nbsp;) และคาดว่าจะคงอยู่ได้ 500–1,000 ปี<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-122">[&nbsp;122&nbsp;]&nbsp;</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-123">[&nbsp;123&nbsp;]&nbsp;</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-124">[&nbsp;124&nbsp;]&nbsp;</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-buried-125">[&nbsp;125&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>โปรแกรม GitHub Archive ยังทำงานร่วมกับพันธมิตรในโครงการ Silica เพื่อพยายามจัดเก็บคลังข้อมูลสาธารณะทั้งหมดเป็นเวลา 10,000 ปี โดยมีเป้าหมายที่จะเขียนข้อมูลลงในโครงสร้างโมเลกุลของ แผ่น&nbsp;<a href="https://en.wikipedia.org/wiki/Quartz_glass">แก้วควอตซ์ โดยใช้เลเซอร์พัลส์&nbsp;</a><a href="https://en.wikipedia.org/wiki/Petahertz">เพตาเฮิร์ต</a>ซ์ที่มีความแม่นยำสูงกล่าวคือเลเซอร์ที่ปล่อยพัลส์หนึ่ง<a href="https://en.wikipedia.org/wiki/Quadrillion">พันล้านล้าน</a>&nbsp;(1,000,000,000,000,000) ครั้งต่อวินาที<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-buried-125">[&nbsp;125&nbsp;]</a></sup></p>

<p>เมื่อวันที่ 25 กรกฎาคม 2562 นักพัฒนาซอฟต์แวร์ที่อยู่ในอิหร่านเขียนบน<a href="https://en.wikipedia.org/wiki/Medium_(website)">Medium</a>ว่า GitHub ได้บล็อกที่เก็บข้อมูลส่วนตัวของเขาและห้ามการเข้าถึง GitHub Pages&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-132">[&nbsp;132&nbsp;]</a></sup>ไม่นานหลังจากนั้น GitHub ยืนยันว่าขณะนี้กำลังบล็อกนักพัฒนาซอฟต์แวร์ใน<a href="https://en.wikipedia.org/wiki/Iran">อิหร่าน</a>ไค<a href="https://en.wikipedia.org/wiki/Crimea">รเมีย</a>คิวบา<a href="https://en.wikipedia.org/wiki/Cuba">เกาหลีเหนือ</a>และซีเรีย<a href="https://en.wikipedia.org/wiki/North_Korea">ไม่</a>ให้เข้าถึงที่เก็บข้อมูลส่วนตัว<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-133">[</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-133">&nbsp;133&nbsp;</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-133">]</a></sup><a href="https://en.wikipedia.org/wiki/Syria">&nbsp;อย่างไรก็ตาม GitHub ได้เปิดให้เข้าถึง GitHub Pages อีกครั้งในอีก ไม่</a>กี่วันต่อมา สำหรับที่เก็บข้อมูลส่วนตัวโดยไม่คำนึงถึงสถานที่ตั้ง นอกจากนี้ยังมีการเปิดเผยว่าการใช้ GitHub ในขณะที่ไปเยือนประเทศที่ถูกคว่ำบาตรอาจส่งผลให้เกิดการกระทำที่คล้ายคลึงกันกับบัญชีของผู้ใช้ GitHub ตอบสนองต่อข้อร้องเรียนและสื่อผ่านโฆษก โดยกล่าวว่า:<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-133"></a></sup></p>

<blockquote class="wp-block-quote"><!-- wp:paragraph -->
<p>GitHub อยู่ภายใต้กฎหมายควบคุมการค้าของสหรัฐฯ และมุ่งมั่นที่จะปฏิบัติตามกฎหมายที่เกี่ยวข้องอย่างครบถ้วน ในขณะเดียวกัน วิสัยทัศน์ของ GitHub คือการเป็นแพลตฟอร์มระดับโลกสำหรับ การทำงานร่วมกัน&nbsp;<a href="https://en.wikipedia.org/wiki/Developer_(software)">ของนักพัฒนา</a>ไม่ว่านักพัฒนาจะอาศัยอยู่ที่ใดก็ตาม ด้วยเหตุนี้ เราจึงให้ความสำคัญอย่างยิ่งต่อความรับผิดชอบของเราในการตรวจสอบข้อกำหนดของรัฐบาลอย่างละเอียดถี่ถ้วน เพื่อให้แน่ใจว่าผู้ใช้และลูกค้าจะไม่ได้รับผลกระทบเกินกว่าที่กฎหมายกำหนด ซึ่งรวมถึงการรักษาบริการคลังข้อมูลสาธารณะ รวมถึงโครงการโอเพนซอร์ส ให้พร้อมใช้งานและเข้าถึงได้ เพื่อสนับสนุนการสื่อสารส่วนบุคคลที่เกี่ยวข้องกับนักพัฒนาในภูมิภาคที่ถูกคว่ำบาตร<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-134">[&nbsp;134&nbsp;]&nbsp;</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-135">[&nbsp;135&nbsp;]</a></sup></p>

<h3 class="wp-block-heading">การเซ็นเซอร์</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>บทความหลัก:&nbsp;</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a href="https://en.wikipedia.org/wiki/Censorship_of_GitHub">การเซ็นเซอร์ของ GitHub</a></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>เมื่อวันที่ 4 ธันวาคม พ.ศ. 2557 รัสเซียได้ขึ้นบัญชีดำ GitHub.com เนื่องจาก GitHub ปฏิเสธที่จะลบคู่มือการฆ่าตัวตายที่ผู้ใช้โพสต์ในตอนแรก<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-137">[&nbsp;137&nbsp;]</a></sup>หลังจากนั้นหนึ่งวัน รัสเซียได้ยกเลิกการบล็อก<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-138">[&nbsp;138&nbsp;]</a></sup>และ GitHub เริ่มบล็อกเนื้อหาและหน้าเว็บเฉพาะในรัสเซีย<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-139">[&nbsp;139&nbsp;]</a></sup>เมื่อวันที่ 31 ธันวาคม พ.ศ. 2557 อินเดียได้บล็อก GitHub.com พร้อมกับเว็บไซต์อื่นอีก 31 เว็บไซต์เนื่องจากเนื้อหาที่สนับสนุน<a href="https://en.wikipedia.org/wiki/ISIS">ISIS</a>ที่ผู้ใช้โพสต์<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-140">[&nbsp;140&nbsp;]</a></sup>การบล็อกถูกยกเลิกในอีกสามวันต่อมา<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-141">[&nbsp;141&nbsp;]</a></sup>เมื่อวันที่ 8 ตุลาคม พ.ศ. 2559 ตุรกีได้บล็อก GitHub เพื่อป้องกันการรั่วไหลของอีเมลจากบัญชีที่ถูกแฮ็กซึ่งเป็นของรัฐมนตรีว่าการกระทรวงพลังงานของประเทศ<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-142">[&nbsp;142&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a href="https://en.wikipedia.org/wiki/DDoS">เมื่อวันที่ 26 มีนาคม พ.ศ. 2558 มีการโจมตี DDoS</a>ขนาดใหญ่เกิดขึ้นกับ GitHub.com ซึ่งกินเวลานานเกือบห้าวัน<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-143">[&nbsp;143&nbsp;]</a></sup>การโจมตีซึ่งดูเหมือนจะมีต้นกำเนิดมาจากประเทศจีน มุ่งเป้าไปที่เนื้อหาของผู้ใช้ที่โฮสต์บน GitHub เป็นหลัก ซึ่งอธิบายวิธีการ หลีกเลี่ยง&nbsp;การ<a href="https://en.wikipedia.org/wiki/Internet_censorship_circumvention">เซ็นเซอร์อินเทอร์เน็ต</a><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-144">[&nbsp;144&nbsp;]&nbsp;</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-145">[&nbsp;145&nbsp;]&nbsp;</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-146">[&nbsp;146&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>เมื่อวันที่ 19 เมษายน 2563 ตำรวจจีนได้จับกุม Chen Mei และ Cai Wei (อาสาสมัครของ Terminus 2049 ซึ่งเป็นโครงการที่โฮสต์บน GitHub) และกล่าวหาว่าพวกเธอ "ก่อเรื่องทะเลาะวิวาทและสร้างปัญหา" Cai และ Chen ได้เก็บถาวรบทความข่าว บทสัมภาษณ์ และเนื้อหาอื่นๆ ที่เผยแพร่ในสื่อจีนและแพลตฟอร์มโซเชียลมีเดียที่ถูกเซ็นเซอร์ในประเทศจีน<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-147">[&nbsp;147&nbsp;]</a></sup></p>

<h3 class="wp-block-heading">สัญญา ICE</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>ดูเพิ่มเติม:&nbsp;</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a href="https://en.wikipedia.org/wiki/Microsoft_and_unions#United_States">ไมโครซอฟต์และสหภาพแรงงาน §&nbsp;&nbsp;สหรัฐอเมริกา</a></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>GitHub มีสัญญามูลค่า 200,000 ดอลลาร์สหรัฐกับ<a href="https://en.wikipedia.org/wiki/U.S._Immigration_and_Customs_Enforcement">สำนักงานตรวจคนเข้าเมืองและศุลกากรของสหรัฐฯ</a>&nbsp;(ICE) สำหรับการใช้ผลิตภัณฑ์ GitHub Enterprise Server ในสถานที่ สัญญานี้ได้รับการต่ออายุในปี 2019 แม้จะมีการคัดค้านภายในจากพนักงาน GitHub จำนวนมาก ในอีเมลที่ส่งถึงพนักงาน ซึ่งต่อมาได้โพสต์ลงในบล็อกของ GitHub เมื่อวันที่ 9 ตุลาคม 2019 ซีอีโอ<a href="https://en.wikipedia.org/wiki/Nat_Friedman">Nat Friedman</a>ระบุว่า "รายได้จากการซื้อนั้นน้อยกว่า 200,000 ดอลลาร์สหรัฐ และไม่มีนัยสำคัญทางการเงินสำหรับบริษัทของเรา" เขาประกาศว่า GitHub ได้ให้คำมั่นที่จะบริจาค 500,000 ดอลลาร์สหรัฐให้กับ "กลุ่มองค์กรไม่แสวงหาผลกำไรที่สนับสนุนชุมชนผู้อพยพที่ตกเป็นเป้าหมายของ<a href="https://en.wikipedia.org/wiki/First_presidency_of_Donald_Trump">รัฐบาลปัจจุบัน</a>&nbsp;"&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-148">[&nbsp;148&nbsp;]</a></sup>ในการตอบสนอง พนักงาน GitHub อย่างน้อย 150 คนได้ลงนามในจดหมายเปิดผนึกเพื่อยืนยันการคัดค้านสัญญาดังกล่าวอีกครั้ง และประณามการละเมิดสิทธิมนุษยชนที่ถูกกล่าวหาโดย ICE&nbsp;ณ วันที่13 พฤศจิกายน&nbsp;2019&nbsp;&nbsp;,คนงาน 5 คนลาออกเนื่องจากสัญญา<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-149">[&nbsp;149&nbsp;]&nbsp;</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-150">[&nbsp;150&nbsp;]&nbsp;</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-151">[&nbsp;151&nbsp;]</a></sup></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>ข้อพิพาทเรื่องสัญญา ICE กลับมาเป็นที่สนใจอีกครั้งในเดือนมิถุนายน 2020 เนื่องจากบริษัทตัดสินใจ<a href="https://en.wikipedia.org/wiki/Master%E2%80%93slave_(technology)#Controversy">ยกเลิกคำศัพท์สาขา "master/slave"</a>ซึ่งได้รับแรงกระตุ้นจากการประท้วงกรณีจอร์จ ฟลอยด์ และขบวนการ<a href="https://en.wikipedia.org/wiki/Black_Lives_Matter">Black Lives Matter&nbsp;</a><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-152">[&nbsp;152&nbsp;]</a></sup>ผู้ที่วิพากษ์วิจารณ์ GitHub อธิบายว่าการเปลี่ยนชื่อสาขาเป็นรูปแบบหนึ่งของ<a href="https://en.wikipedia.org/wiki/Performative_activism">การแสดงออกทางการเมือง</a>และเรียกร้องให้ GitHub ยกเลิกสัญญากับ ICE แทน<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-153">[&nbsp;153&nbsp;]</a></sup>จดหมายเปิดผนึกจากสมาชิกของชุมชนโอเพนซอร์สถูกเผยแพร่บน GitHub ในเดือนธันวาคม 2019 เรียกร้องให้บริษัทเลิกสัญญากับ ICE และให้ความโปร่งใสมากขึ้นในการดำเนินธุรกิจและความร่วมมือ จดหมายฉบับนี้มีผู้ลงนามมากกว่า 700 คน<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-154">[&nbsp;154&nbsp;]</a></sup></p>

<h3 class="wp-block-heading">ความคิดเห็นเกี่ยวกับการจลาจลในรัฐสภาและการไล่พนักงานออก</h3>
<!-- /wp:heading -->

<!-- wp:paragraph -->
<p>ในเดือนมกราคม 2021 GitHub ไล่พนักงานคนหนึ่งออกหลังจากที่เขาแสดงความกังวลต่อเพื่อนร่วมงานหลังจาก<a href="https://en.wikipedia.org/wiki/January_6_United_States_Capitol_attack">การโจมตีอาคารรัฐสภาสหรัฐฯ เมื่อวันที่ 6 มกราคม</a>โดยเรียกผู้ก่อจลาจลบางคนว่า "&nbsp;<a href="https://en.wikipedia.org/wiki/Neo-Nazism">นาซี</a>&nbsp;"&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-155">[&nbsp;155&nbsp;]</a></sup>หลังจากการสอบสวน COO ของ GitHub กล่าวว่ามี "ข้อผิดพลาดในการตัดสินใจและขั้นตอนที่สำคัญ" ในการตัดสินใจไล่พนักงานออกของบริษัท ผลจากการสอบสวน GitHub ได้ติดต่อพนักงานคนดังกล่าว และหัวหน้าฝ่ายทรัพยากรบุคคลของบริษัทได้ลาออก<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-156">[&nbsp;156&nbsp;]&nbsp;</a></sup><sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-157">[&nbsp;157&nbsp;]</a></sup></p>

<h3 class="wp-block-heading">การรั่วไหลของซอร์สโค้ด Twitter</h3>

<p>ในปี 2023 ส่วนหนึ่งของแพลตฟอร์มโซเชียลมีเดีย<a href="https://en.wikipedia.org/wiki/Twitter">Twitter</a>ถูกอัปโหลดไปยัง GitHub&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-158">[&nbsp;158&nbsp;]</a></sup>การรั่วไหลนี้ได้รับการรายงานครั้งแรกโดย<em>New York Times</em>และเป็นส่วนหนึ่งของเอกสารทางกฎหมายที่ Twitter ยื่นต่อ<a href="https://en.wikipedia.org/wiki/United_States_District_Court_for_the_Northern_District_of_California">ศาลแขวงสหรัฐอเมริกาประจำเขตเหนือของแคลิฟอร์เนีย</a>&nbsp;Twitter อ้างว่าการโพสต์ดังกล่าวละเมิดลิขสิทธิ์ที่เป็นของตน และขอข้อมูลจากศาลเพื่อระบุตัวผู้ใช้ที่โพสต์ซอร์สโค้ดไปยัง GitHub ภายใต้ชื่อผู้ใช้ "FreeSpeechEnthusiast"&nbsp;<sup><a href="https://en.wikipedia.org/wiki/GitHub#cite_note-159">[&nbsp;159&nbsp;]</a></sup></p>

<h2 class="wp-block-heading">แผนกต้อนรับ</h2>
